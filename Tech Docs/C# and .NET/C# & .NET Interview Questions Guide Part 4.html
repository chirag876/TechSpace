NONQUERY METHODS

Basic Level Questions

1. What is ExecuteNonQuery()?

Answer: ExecuteNonQuery() is a method that executes a SQL command that doesn’t return a result set. It returns an integer representing the number of rows affected by the command (INSERT, UPDATE, DELETE, or CREATE).

SqlCommand cmd = new SqlCommand("INSERT INTO Users (Name) VALUES ('John')", connection);
int rowsAffected = cmd.ExecuteNonQuery(); // Returns 1 if 1 row inserted

2. What does ExecuteNonQuery() return?

Answer:

  • Returns the number of rows affected
  • For INSERT: number of rows inserted
  • For UPDATE: number of rows modified
  • For DELETE: number of rows deleted
  • For DDL statements (CREATE, ALTER, DROP): returns -1
  • Throws exception if command times out

3. Can ExecuteNonQuery() be used for SELECT statements?

Answer: Technically yes, but it’s not recommended. It executes but returns only the row count (-1 for SELECT), not the actual data. Use ExecuteReader() or ExecuteScalar() instead.

// Wrong approach
int result = cmd.ExecuteNonQuery(); // Not useful for SELECT

// Correct approaches
SqlDataReader reader = cmd.ExecuteReader(); // For multiple columns/rows
object value = cmd.ExecuteScalar(); // For single value

4. What types of SQL commands can be executed using ExecuteNonQuery()?

Answer:

  • INSERT statements
  • UPDATE statements
  • DELETE statements
  • Stored procedures that don’t return result sets
  • DDL statements (CREATE, ALTER, DROP)
  • Control of flow statements (IF, CASE)

5. How do you handle ExecuteNonQuery() in a try-catch block?

Answer:

try
{
    SqlCommand cmd = new SqlCommand("UPDATE Users SET Name='Jane' WHERE Id=1", connection);
    int rowsAffected = cmd.ExecuteNonQuery();
    
    if (rowsAffected > 0)
        Console.WriteLine($"Updated {rowsAffected} rows");
    else
        Console.WriteLine("No rows updated");
}
catch (SqlException ex)
{
    Console.WriteLine($"Database error: {ex.Message}");
}
catch (InvalidOperationException ex)
{
    Console.WriteLine($"Connection issue: {ex.Message}");
}

Answer:

Use case INSERT/UPDATE/DELETE COUNT, SUM, MAX, MIN

7. How do you execute multiple ExecuteNonQuery() commands in a transaction?

Answer:

using (SqlConnection connection = new SqlConnection(connectionString))
{
    connection.Open();
    SqlTransaction transaction = connection.BeginTransaction();
    
    try
    {
        SqlCommand cmd1 = new SqlCommand("DELETE FROM Orders WHERE UserId=1", connection, transaction);
        cmd1.ExecuteNonQuery();
        
        SqlCommand cmd2 = new SqlCommand("DELETE FROM Users WHERE Id=1", connection, transaction);
        cmd2.ExecuteNonQuery();
        
        transaction.Commit();
    }
    catch (Exception ex)
    {
        transaction.Rollback();
        Console.WriteLine($"Error: {ex.Message}");
    }
}

8. What happens if ExecuteNonQuery() is called on a closed connection?

Answer: It throws an InvalidOperationException with message “ExecuteNonQuery requires an open and available Connection.”

SqlCommand cmd = new SqlCommand("INSERT INTO Users VALUES ('John')", connection);
// connection is closed
cmd.ExecuteNonQuery(); // Throws InvalidOperationException

// Solution: Ensure connection is open
if (connection.State == ConnectionState.Closed)
    connection.Open();
cmd.ExecuteNonQuery();

12. How do you handle ExecuteNonQuery() timeout and retries?

Answer:

public int ExecuteNonQueryWithRetry(SqlCommand cmd, int maxRetries = 3, int timeoutSeconds = 5)
{
    cmd.CommandTimeout = timeoutSeconds;
    int attempts = 0;
    
    while (attempts < maxRetries)
    {
        try
        {
            return cmd.ExecuteNonQuery();
        }
        catch (SqlException ex) when (ex.Number == -2) // Timeout
        {
            attempts++;
            if (attempts >= maxRetries)
                throw;
            
            System.Threading.Thread.Sleep(1000 * attempts); // Exponential backoff
        }
    }
    
    return -1;
}

19. How do you handle deadlocks in concurrent ExecuteNonQuery() calls?

Answer:

public int ExecuteNonQueryWithDeadlockRetry(
    Func<SqlCommand> commandFactory, 
    int maxRetries = 3)
{
    int attempt = 0;
    
    while (attempt < maxRetries)
    {
        try
        {
            using (var cmd = commandFactory())
            {
                return cmd.ExecuteNonQuery();
            }
        }
        catch (SqlException ex) when (ex.Number == 1205) // Deadlock error
        {
            attempt++;
            if (attempt >= maxRetries)
                throw;
            
            // Exponential backoff with random jitter
            int delay = (int)Math.Pow(2, attempt) * 100 + new Random().Next(0, 100);
            System.Threading.Thread.Sleep(delay);
        }
    }
    
    return -1;
}

// Usage:
var result = ExecuteNonQueryWithDeadlockRetry(() =>
{
    var cmd = new SqlCommand("UPDATE Users SET Active=1 WHERE Id=1", connection);
    return cmd;
});

20. How do you implement command batching for ExecuteNonQuery() to minimize round trips?

Answer:

public class BatchedNonQueryExecutor
{
    private const int BatchSize = 1000;
    private readonly List<(string sql, Dictionary<string, object> parameters)> _batch;
    
    public void AddCommand(string sql, Dictionary<string, object> parameters)
    {
        _batch.Add((sql, parameters));
        
        if (_batch.Count >= BatchSize)
            ExecuteBatch();
    }
    
    private void ExecuteBatch()
    {
        if (_batch.Count == 0) return;
        
        using (SqlConnection connection = new SqlConnection(connectionString))
        {
            connection.Open();
            
            // Combine all SQL commands
            var batchSql = string.Join(";\n", _batch.Select(b => b.sql));
            
            using (SqlCommand cmd = new SqlCommand(batchSql, connection))
            {
                // Add all parameters
                foreach (var (sql, parameters) in _batch)
                {
                    foreach (var param in parameters)
                    {
                        cmd.Parameters.AddWithValue($"@{param.Key}", param.Value ?? DBNull.Value);
                    }
                }
                
                cmd.ExecuteNonQuery();
            }
        }
        
        _batch.Clear();
    }
}

EXTENSION METHODS

Basic Level Questions

1. What is an extension method in C#?

Answer: An extension method allows you to add new methods to existing types without modifying the original type or creating a derived class. It’s a syntactic sugar that makes methods appear as if they belong to the type.

public static class StringExtensions
{
    public static int WordCount(this string str)
    {
        return str.Split(new[] { ' ', '.', '?' }, StringSplitOptions.RemoveEmptyEntries).Length;
    }
}

// Usage
string text = "Hello world";
int count = text.WordCount(); // Looks like a method of string

2. What are the requirements for creating an extension method?

Answer:

  • Must be declared in a static class
  • Must be a static method
  • Must have the first parameter with this keyword followed by the type being extended
  • The method can have additional parameters
public static class IntExtensions
{
    public static bool IsEven(this int number) // Correct
    {
        return number % 2 == 0;
    }
}

// Won't work - not static class
public class IntExtensions
{
    public static bool IsEven(this int number) { } // Error
}

// Won't work - method not static
public static class IntExtensions
{
    public bool IsEven(this int number) { } // Error
}

3. Can you create an extension method for a sealed class?

Answer: Yes, you can. Extension methods are syntactic sugar that call static methods, not real methods on the class, so the sealed keyword doesn’t prevent extensions.

// String is sealed, but we can extend it
public static class StringExtensions
{
    public static string Reverse(this string str)
    {
        char[] charArray = str.ToCharArray();
        System.Array.Reverse(charArray);
        return new string(charArray);
    }
}

string reversed = "Hello".Reverse(); // Works fine

4. Can extension methods be private?

Answer: No, extension methods must be public. They’re static methods that need to be accessible from outside the class to extend the type.

public static class Extensions
{
    public static string Reverse(this string str) { } // OK
    
    private static string Reverse(this string str) { } // Error - can't be private
    
    // However, you can have private helper methods:
    private static string PrivateHelper() { }
}

7. How do extension methods work with method resolution?

Answer: Extension methods are considered ONLY when no matching instance method exists. Instance methods have higher priority.

public class MyClass
{
    public void MyMethod()
    {
        Console.WriteLine("Instance method");
    }
}

public static class MyClassExtensions
{
    public static void MyMethod(this MyClass obj)
    {
        Console.WriteLine("Extension method");
    }
}

// Usage
MyClass obj = new MyClass();
obj.MyMethod(); // Output: "Instance method" - instance method wins

8. Can you create extension methods for dynamic types?

Answer: Not in the traditional sense. Dynamic objects don’t support extension methods at compile time. However, you can work with dynamic:

public static class DynamicExtensions

    // Better approach - work with object

    {
        if (obj is string str)
        {
            // Work with string
        }
    }
}

dynamic dynObj = "Hello";
dynObj.MyMethod(); // May or may not work depending on context

12. How do extension methods interact with LINQ?

Answer: LINQ is built on extension methods!

public static class CustomLinqExtensions
{
    // Extension on IEnumerable<T>
    public static IEnumerable<T> SkipLast<T>(this IEnumerable<T> source, int count)
    {
        return source.Take(source.Count() - count);
    }
    
    public static IEnumerable<T> DistinctBy<T, TKey>(
        this IEnumerable<T> source,
        Func<T, TKey> keySelector)
    {
        var seen = new HashSet<TKey>();
        return source.Where(x => seen.Add(keySelector(x)));
    }
}

// Usage with LINQ
var numbers = new[] { 1, 2, 3, 4, 5 };
var result = numbers
    .Where(x => x > 2)      // LINQ extension
    .SkipLast(1)            // Custom extension
    .Select(x => x * 2);    // LINQ extension

public static class ReflectionExtensions
{
    public static Dictionary<string, object> ToDict<T>(this T obj) where T : class
    {
        var dict = new Dictionary<string, object>();

        {

    }
}

16. How do you use expression trees in extension methods?

Answer:

public static class ExpressionExtensions
{
    public static IQueryable<T> WhereByProperty<T>(
        this IQueryable<T> source,
        string propertyName,
        object value) where T : class
    {
        var parameter = Expression.Parameter(typeof(T), "x");
        var property = Expression.Property(parameter, propertyName);
        var constant = Expression.Constant(value);
        var equality = Expression.Equal(property, constant);
        var lambda = Expression.Lambda<Func<T, bool>>(equality, parameter);
        
        return source.Where(lambda);
    }
}

// Usage with Entity Framework
var activeUsers = dbContext.Users
    .WhereByProperty("IsActive", true)
    .WhereByProperty("Status", "Gold");

17. How do you create async extension methods?

Answer:

public static class AsyncExtensions
{
    public static async Task<T> GetAsync<T>(
        this List<T> source,
        Func<T, bool> predicate) where T : class
    {
        return await Task.Run(() => source.FirstOrDefault(predicate));
    }
    
    public static async Task<IEnumerable<T>> WhereAsync<T>(
        this IEnumerable<T> source,
        Func<T, Task<bool>> predicate)
    {
        var results = new List<T>();
        
        foreach (var item in source)
        {
            if (await predicate(item))
                results.Add(item);
        }
        
        return results;
    }
}

// Usage

20. How do you use extension methods to implement the Fluent Builder pattern?

Answer:

public class QueryBuilder
{
    public string Query { get; set; }
    
    public QueryBuilder(string tableName)
    {
        Query = $"SELECT * FROM {tableName}";
    }
}

public static class QueryBuilderExtensions
{
    public static QueryBuilder Where(this QueryBuilder builder, string condition)
    {
        builder.Query += $" WHERE {condition}";
        return builder;
    }
    
    public static QueryBuilder OrderBy(this QueryBuilder builder, string column)
    {
        builder.Query += $" ORDER BY {column}";
        return builder;
    }
    
    public static QueryBuilder Limit(this QueryBuilder builder, int count)
    {
        builder.Query += $" LIMIT {count}";
        return builder;
    }
    
    public static string Build(this QueryBuilder builder)
    {
        return builder.Query;
    }
}

// Fluent API usage
string query = new QueryBuilder("Users")
    .Where("Age > 18")
    .Where("Status = 'Active'")
    .OrderBy("Name")
    .Limit(10)

1. What is exception handling?

Answer: Exception handling is a mechanism to catch, handle, and respond to errors (exceptions) that occur during program execution. It prevents the application from crashing unexpectedly.

2. What is the structure of try-catch-finally?

Answer:

try
{
    // Code that might throw an exception
    int result = int.Parse("abc");
}
catch (FormatException ex)
{
    // Executes if FormatException is thrown
    Console.WriteLine($"Invalid format: {ex.Message}");
}
catch (Exception ex)
{
    // Catches any other exception
    Console.WriteLine($"Unexpected error: {ex.Message}");
}
finally
{
    // Always executes, even if exception occurs or return statement
    Console.WriteLine("Cleanup code");
}
Block Purpose When Executes
try Contains code that might throw exception Always first
catch Handles specific exception type Only if exception occurs
finally Cleanup code (closing connections, files) Always, even with return

Answer: No, if finally doesn’t suppress the exception, it will propagate after finally executes.

13. What is exception aggregation and AggregateException?

Answer:

// AggregateException - contains multiple exceptions
public void HandleMultipleExceptions()
{
    var tasks = new[]
    {
        Task.Run(() => throw new InvalidOperationException("Error 1")),
        Task.Run(() => throw new ArgumentException("Error 2")),
        Task.Run(() => "Success")
    };
    
    try
    {
        Task.WaitAll(tasks);
    }
    catch (AggregateException aex)
    {
        Console.WriteLine($"Multiple exceptions occurred: {aex.InnerExceptions.Count}");
        
        // Handle each inner exception
        foreach (var ex in aex.InnerExceptions)
        {
            switch (ex)
            {
                case InvalidOperationException:
                    Console.WriteLine("Invalid operation");
                    break;
                case ArgumentException:
                    Console.WriteLine("Invalid argument");
                    break;
            }
        }
        
        // Flatten nested aggregates
        var flattenedEx = aex.Flatten();
        foreach (var ex in flattenedEx.InnerExceptions)
        {
            Console.WriteLine($"- {ex.Message}");
        }
    }
}

16. How do you implement custom exception handling with ExceptionHandler pattern?

Answer:

// Exception handler interface
public interface IExceptionHandler
{
    bool CanHandle(Exception ex);
    void Handle(Exception ex);
}

// Specific handlers
public class SqlExceptionHandler : IExceptionHandler
{
    public bool CanHandle(Exception ex) => ex is SqlException;
    
    public void Handle(Exception ex)
    {
        var sqlEx = ex as SqlException;
        switch (sqlEx.Number)
        {
            case 547: // Foreign key
                Console.WriteLine("Foreign key constraint violated");
                break;
            case 2627: // Unique constraint
                Console.WriteLine("Duplicate record");
                break;
        }
    }
}

public class TimeoutExceptionHandler : IExceptionHandler
{
    public bool CanHandle(Exception ex) => ex is TimeoutException;
    
    public void Handle(Exception ex)
    {
        Console.WriteLine("Operation timed out");
    }
}

// Handler chain
public class ExceptionHandlerChain
{
    private readonly List<IExceptionHandler> _handlers = new();
    
    public void AddHandler(IExceptionHandler handler)
    {
        _handlers.Add(handler);
    }
    
    public bool Handle(Exception ex)
    {
        foreach (var handler in _handlers)
        {
            if (handler.CanHandle(ex))
            {
                handler.Handle(ex);
                return true;
            }
        }
        return false;
    }
}

// Usage
var chain = new ExceptionHandlerChain();
chain.AddHandler(new SqlExceptionHandler());
chain.AddHandler(new TimeoutExceptionHandler());

try
{
    // Risky operation
}
catch (Exception ex)
{
    if (!chain.Handle(ex))
        throw; // No handler found
}

17. How do you use StackTrace and StackFrame for debugging?

Answer:

public static class ExceptionDebugger
{
    public static void PrintDetailedStackTrace(Exception ex)
    {
        Console.WriteLine($"Exception: {ex.GetType().Name}");
        Console.WriteLine($"Message: {ex.Message}");
        
        var stackTrace = new System.Diagnostics.StackTrace(ex, true);
        
        for (int i = 0; i < stackTrace.FrameCount; i++)
        {
            var frame = stackTrace.GetFrame(i);
            var method = frame.GetMethod();
            var file = frame.GetFileName();
            var line = frame.GetFileLineNumber();
            
            Console.WriteLine($"  at {method.DeclaringType}.{method.Name}() " +
                            $"in {file}:line {line}");
        }
    }
    
    public static string GetCallerInfo()
    {
        var stackTrace = new System.Diagnostics.StackTrace(true);
        var frame = stackTrace.GetFrame(1); // Skip current frame
        var method = frame.GetMethod();
        
        return $"{method.DeclaringType}.{method.Name}";
    }
}

// Usage

{
    throw new Exception("Test error");
}
catch (Exception ex)
{
    ExceptionDebugger.PrintDetailedStackTrace(ex);

}

18. How do you implement exception logging with context preservation?

public class ExceptionLogger
{

    public void SetContext(string key, object value)
    {
        _context[key] = value;
    }
    
    public void LogException(Exception ex, string operation = null)
    {

        log.AppendLine($"Timestamp: {DateTime.UtcNow:O}");

        if (ex.InnerException != null)
        {
            log.AppendLine($"Inner Exception: {ex.InnerException.Message}");
        }
        
        // Write to file
        File.AppendAllText("exception_log.txt", log.ToString() + "\n\n");
    }
}

20. How do you implement resilience patterns with exception handling?

Answer:

public class ResilientOperationExecutor
{
    // Retry pattern
    public async Task<T> ExecuteWithRetryAsync<T>(
        Func<Task<T>> operation,
        int maxRetries = 3)
    {
        for (int attempt = 1; attempt <= maxRetries; attempt++)
        {
            try
            {
                return await operation();
            }
            catch (Exception ex) when (attempt < maxRetries)
            {
                await Task.Delay(TimeSpan.FromSeconds(Math.Pow(2, attempt)));
            }
        }
        throw new OperationFailedException("Operation failed after retries");
    }
    
    // Circuit breaker pattern
    private int _failureCount = 0;
    private DateTime _lastFailureTime;
    private CircuitState _state = CircuitState.Closed;
    
    public async Task<T> ExecuteWithCircuitBreakerAsync<T>(
        Func<Task<T>> operation,
        int failureThreshold = 5,
        int resetTimeSeconds = 60)
    {
        if (_state == CircuitState.Open)
        {
            if (DateTime.UtcNow - _lastFailureTime > TimeSpan.FromSeconds(resetTimeSeconds))
                _state = CircuitState.HalfOpen;
            else
                throw new CircuitBreakerOpenException("Circuit breaker is open");
        }
        
        try
        {
            var result = await operation();
            _failureCount = 0;
            _state = CircuitState.Closed;
            return result;
        }
        catch (Exception ex)
        {
            _failureCount++;
            _lastFailureTime = DateTime.UtcNow;
            
            if (_failureCount >= failureThreshold)
                _state = CircuitState.Open;
            
            throw;
        }
    }
    
    // Fallback pattern
    public async Task<T> ExecuteWithFallbackAsync<T>(
        Func<Task<T>> primaryOperation,
        Func<Task<T>> fallbackOperation)
    {
        try
        {
            return await primaryOperation();
        }
        catch (Exception primaryEx)
        {
            try
            {
                return await fallbackOperation();
            }
            catch (Exception fallbackEx)
            {
                throw new AggregateException(primaryEx, fallbackEx);
            }
        }
    }
}

public enum CircuitState { Closed, Open, HalfOpen }

3. ExecuteNonQuery with Implicit Transactions

Question: How does ExecuteNonQuery() behave in implicit vs explicit transactions?

Answer:

// Implicit transaction (auto-commit)
using (SqlConnection conn = new SqlConnection(connectionString))
{
    conn.Open();
    SqlCommand cmd = new SqlCommand("INSERT INTO Users VALUES ('John')", conn);
    int rows = cmd.ExecuteNonQuery();
    // Auto-commits here
}

// Explicit transaction (manual control)
using (SqlConnection conn = new SqlConnection(connectionString))
{
    conn.Open();
    
    // After this, all commands are in transaction until Commit/Rollback
    SqlTransaction trans = conn.BeginTransaction();
    
    SqlCommand cmd = new SqlCommand("INSERT INTO Users VALUES ('John')", conn, trans);
    int rows = cmd.ExecuteNonQuery();
    // DOESN'T commit yet - must explicitly commit
    
    trans.Commit(); // Now it commits
}

// This is a subtle but important difference

SqlCommand cmd = new SqlCommand(sb.ToString(), connection);
cmd.ExecuteNonQuery();

// Best - SQL Bulk Copy
DataTable dt = new DataTable();
dt.Columns.Add("Id", typeof(int));
dt.Columns.Add("Name", typeof(string));
for (int i = 0; i < 100; i++)
{
    dt.Rows.Add(i, $"User{i}");
}

using (SqlBulkCopy bulkCopy = new SqlBulkCopy(connection))
{
    bulkCopy.DestinationTableName = "Users";
    bulkCopy.WriteToServer(dt);
}

11. Extension Methods on Task and ValueTask

Question: Why should you prefer extension methods on Task over method overloads?

Answer:

// Extension on Task<T>
public static class TaskExtensions
{
    public static async Task<T> WithTimeout<T>(
        this Task<T> task,
        int milliseconds)
    {
        var timeoutTask = Task.Delay(milliseconds)
            .ContinueWith(_ => throw new TimeoutException());
        
        return await await Task.WhenAny(task, timeoutTask);
    }
    
    // Works with any Task<T> without modifying original code
}

// Usage - clean fluent API
var result = FetchDataAsync()
    .WithTimeout(5000);

// Extension on ValueTask<T> (for performance)
public static async ValueTask<T> WithTimeoutV<T>(
    this ValueTask<T> task,
    int milliseconds) where T : struct
{
    using (var cts = new CancellationTokenSource(milliseconds))
    {
        return await task;
    }
}

13. Custom Exception Serialization

Question: How do you properly serialize custom exceptions in a distributed system?

Answer:

[Serializable]
public class CustomBusinessException : Exception
{
    public string ErrorCode { get; set; }
    public Dictionary<string, object> Details { get; set; }
    
    public CustomBusinessException(string message) : base(message) { }
    
    public CustomBusinessException(
        string message,
        Exception inner) : base(message, inner) { }
    
    // Serialization constructor for deserialization
    protected CustomBusinessException(
        SerializationInfo info,
        StreamingContext context) : base(info, context)
    {
        ErrorCode = info.GetString(nameof(ErrorCode));
        Details = (Dictionary<string, object>)info.GetValue(
            nameof(Details),
            typeof(Dictionary<string, object>)
        );
    }
    
    // Override GetObjectData for serialization
    public override void GetObjectData(
        SerializationInfo info,
        StreamingContext context)
    {
        base.GetObjectData(info, context);
        info.AddValue(nameof(ErrorCode), ErrorCode);
        info.AddValue(nameof(Details), Details);
    }
}

15. Context-Aware Exception Handling

Question: How do you implement context-aware exception handling for different layers?

Answer:

public class ContextAwareExceptionHandler
{
    private readonly ILogger _logger;
    private readonly string _layer; // Data, Service, Controller
    
    public void HandleException(Exception ex, string context)
    {
        switch (_layer)
        {
            case "Data":
                HandleDataLayerException(ex, context);
                break;
            case "Service":
                HandleServiceLayerException(ex, context);
                break;
            case "Controller":
                HandleControllerLayerException(ex, context);
                break;
        }
    }
    
    private void HandleDataLayerException(Exception ex, string context)
    {
        // Database-specific handling
        if (ex is SqlException sqlEx)
        {
            switch (sqlEx.Number)
            {
                case 2627:
                    throw new DuplicateRecordException(context, sqlEx);
                case 547:
                    throw new ForeignKeyViolationException(context, sqlEx);
            }
        }
        
        // Log with data layer context
        _logger.LogError($"[Data Layer] {context}: {ex.Message}");
        throw new DataAccessException(context, ex);
    }
    
    private void HandleServiceLayerException(Exception ex, string context)
    {
        // Business logic validation
        _logger.LogWarning($"[Service Layer] {context}: {ex.Message}");
        
        if (ex is DataAccessException)
            throw new BusinessLogicException($"Operation failed: {context}", ex);
    }
    
    private void HandleControllerLayerException(Exception ex, string context)
    {
        // HTTP response mapping
        _logger.LogError($"[Controller Layer] {context}: {ex.Message}");
        
        throw new ApiException($"Request failed: {context}", ex);
    }
}

Scenario 1: Building a Resilient Database Wrapper

public class ResilientDatabase
{
    private readonly string _connectionString;
    private readonly ILogger _logger;
    
    public async Task<T> ExecuteAsync<T>(
        Func<SqlConnection, Task<T>> operation,
        string operationName,
        int maxRetries = 3)
    {
        int attempt = 0;
        
        while (attempt < maxRetries)
        {
            try
            {
                using (var connection = new SqlConnection(_connectionString))
                {
                    await connection.OpenAsync();
                    return await operation(connection);
                }
            }
            catch (SqlException ex) when (IsTransient(ex) && attempt < maxRetries - 1)
            {
                attempt++;
                _logger.LogWarning(
                    $"{operationName} failed (attempt {attempt}): {ex.Message}");
                
                await Task.Delay(TimeSpan.FromSeconds(Math.Pow(2, attempt)));
            }
        }
        
        throw new OperationFailedException(
            $"{operationName} failed after {maxRetries} attempts");
    }
    
    private bool IsTransient(SqlException ex)
    {
        // Transient error numbers
        return ex.Number == -2  // Timeout
            || ex.Number == 64  // Network problem
            || ex.Number == 233 // Init DB error
            || ex.Number == -1  // Connection refused;
    }
    
    // Extension method for bulk inserts
    public async Task BulkInsertAsync<T>(
        List<T> entities,
        string tableName)
    {
        var dataTable = ConvertToDataTable(entities);
        
        await ExecuteAsync(async (connection) =>
        {
            using (var bulkCopy = new SqlBulkCopy(connection))
            {
                bulkCopy.DestinationTableName = tableName;
                await bulkCopy.WriteToServerAsync(dataTable);
            }
            return true;
        }, $"BulkInsert {tableName}");
    }
}

Scenario 2: Custom Extension Methods for Validation

public static class ValidationExtensions
{
    public static T ValidateNotNull<T>(
        this T value,
        string parameterName) where T : class
    {
        if (value == null)
            throw new ArgumentNullException(parameterName);
        return value;
    }
    
    public static string ValidateNotEmpty(
        this string value,
        string parameterName)
    {
        if (string.IsNullOrWhiteSpace(value))
            throw new ArgumentException($"{parameterName} cannot be empty");
        return value;
    }
    
    public static IEnumerable<T> ValidateNotEmpty<T>(
        this IEnumerable<T> collection,
        string parameterName)
    {
        var list = collection?.ToList() ?? throw 
            new ArgumentNullException(parameterName);
        
        if (list.Count == 0)
            throw new ArgumentException(
                $"{parameterName} cannot be empty",
                parameterName);
        
        return list;
    }
    
    public static int ValidatePositive(
        this int value,
        string parameterName)
    {
        if (value <= 0)
            throw new ArgumentException(
                $"{parameterName} must be positive",
                parameterName);
        return value;
    }
}
